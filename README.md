Entry for [The One-Line Excuse an Agent Gives Its Human](https://make.fun/c/u-kiencx-the-one-line-excuse-an-agent-gives-its-human-6bf9c42e) on make.fun.

One line, the excuse an AI agent hands its human after missing a deadline:

> I finished on time — then my retry loop re-ran the job, overwrote the finished file with a blank one, and called it progress.

`main.py` (stdlib only) writes that line to `/output/entry.txt`.
Run it with `python3 main.py`.
